# 11.11 StepUp 워킹데이 페이지

QR과 프로필 링크로 폰에서 바로 여는 이벤트 페이지. 정적 파일이라 빌드와 서버 개발이 필요 없음.

- 올릴 주소: https://stepupcrew.com/11events/
- 조작판 미리보기: 주소 끝에 `#preview`

## 올리는 법

1. `index.html`, `app.js`, `assets/`를 사이트 저장소 `web/11events/`에 복사
2. `web/_headers`에 공통 CSP가 걸리면 이 경로에 `style-src 'unsafe-inline'`, `font-src data:` 허용. 인라인 스크립트 없음
3. 배포 후 폰으로 접속, 버튼을 눌러 사전 등록창(`/#join`)이 열리는지 확인

## 설정: `assets/config.js`

| 값 | 뜻 |
|---|---|
| `total` | 다 같이 걸은 걸음 합계. 매일 21시 전 입력. 비우면 「집계 준비 중」 |
| `proof` | 걸음 인증 양식 주소. 넣으면 11/7~11/12 버튼이 「걸음 인증하기」로 바뀜 |
| `share` | 링크 복사 주소 |
| `url`, `key` | 합계 자동 연동을 만들 때만 사용. 초안은 `개발팀_연동메모.md` |

## 오픈 전 필수

- 걸음 인증 제출 양식 결정(11/7 전). 지금은 받을 곳이 없음
- 실제 폰과 QR 스캔 확인. QR 파일은 `QR/`, 담긴 주소는 `https://stepupcrew.com/11events/?utm_source=qr&utm_medium=offline`
